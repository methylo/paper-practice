# paper-practice

논문 초보자가 5,000자 규모의 연습 논문을 처음부터 끝까지 작성하며 논문 작업의 전체 흐름을 익히는 수업·워크숍용 스킬입니다.

이 스킬은 실제 학위논문이나 학술지 투고 원고를 대신 작성하지 않습니다. 문헌 3~5편과 작은 원자료를 사용해 연구 질문, 판정 규칙, 근거카드, 단락 작성, 인용 점검을 축소된 규모로 경험하도록 설계했습니다.

## 주요 결과물

- 연구 질문 3개와 판정 규칙
- 5개 섹션·12개 단락 구성
- 원문에서 근거 위치를 확인한 문헌 3~5편의 근거카드
- 이론적 배경, 연구 방법, 연구 결과, 서론, 결론 초안
- 문장–근거 대응표
- APA 7판 참고문헌 초안
- 5,000자 연습 원고와 회고 5줄

## 진행 단계

```text
STEP 0  실습 준비 — 주제·자료 확인, 실증형·논증형 분기
STEP 1  연구 질문 3개와 판정 규칙 확정
STEP 2  목차와 12개 단락 배치
STEP 3  자료 수집과 근거카드
STEP 4  이론적 배경 작성
STEP 5  연구 방법·결과 작성
STEP 6  서론·결론 작성
STEP 7  문장–근거 점검과 출처 표기
STEP 8  완성본과 회고 5줄
```

## 설치

1. GitHub Releases에서 `paper-practice-v1.2.0.skill`을 내려받습니다.
2. Claude의 사용자 지정 스킬 관리 화면에서 내려받은 파일을 추가합니다.
3. 새 대화에서 아래 설치 확인 문장을 입력합니다.

```text
paper-practice 스킬이 설치됐는지 확인해줘.
하는 일과 첫 입력만 1줄로 알려주고, 아직 시작하지 마.
```

Claude 이외의 Agent Skills 호환 환경에서는 `paper-practice/` 폴더를 해당 환경의 스킬 경로에 설치할 수 있습니다. 환경별 도구와 호출 방식은 별도 확인이 필요합니다.

## 준비물

- 연구할 주제 한 줄
- 원문을 열 수 있는 문헌 3~5편 또는 문헌 검색이 가능한 웹 환경
- 관찰 기록·사례·이미지·짧은 인터뷰 중 원자료 1건
- 원자료가 없으면 문헌 기반 논증형 실습으로 진행

웹에서 원문을 열 수 없으면 PDF를 직접 첨부해야 합니다. 검색 결과와 초록만 확인한 자료는 인용하지 않습니다.

## 시작 예시

```text
paper-practice 시작해줘.
- 주제: 디자인 전공 학부 과제 제출물의 생성형 AI 사용 표기 방식
- 가진 자료: 문헌 3편, 과제 제출물 사례 3건, 코딩 시트
- 원자료는 교육용 가상 자료이므로 결과에 '가상 예시' 표시를 유지해줘
- STEP 0부터 순서대로 진행하고 각 단계가 끝나면 확인받아줘
```

일부 단계까지만 진행할 수도 있습니다.

```text
paper-practice STEP 3까지만 진행해줘.
원문 근거카드가 몇 편 나오는지 확인한 뒤 다음 단계를 결정할게.
```

## 예제 자료

`examples/AI표기방식-실습자료/`에는 다음 교육용 자료가 들어 있습니다.

- `01_가진자료_문헌.md`: 실제 문헌 3편과 직접 검색할 문헌 1편
- `02_원자료_과제제출물.md`: 교육용 가상 과제 제출물 3건
- `03_코딩시트_표기분석.md`: 표기 위치·내용과 기록을 분석하는 시트

가상 원자료에서 얻은 결과에는 항상 `가상 예시`를 표시해야 합니다.

## 사용 범위

- 수업·워크숍에서 논문 작성 과정을 경험하는 용도입니다.
- 결과물에는 `실습 원고` 표시를 유지합니다.
- 실습 원고를 학위논문·학술지 논문·과제물로 그대로 제출하지 않습니다.
- 확인하지 못한 저자·연도·제목·DOI·페이지를 만들지 않습니다.
- 원문에서 근거 위치를 확인한 자료만 인용합니다.
- 실제 학생 자료를 사용할 때는 소속 기관의 연구윤리·개인정보·동의 절차를 따릅니다.
