# 코딩 시트 — 표기 분석 도구

> 원자료를 결과로 바꾸는 도구다. 이 시트를 채우는 절차가 논문의 Ⅲ장 연구 방법이 된다.
> 시트를 채우기 전에 STEP 1의 판정 규칙을 확정한다. 규칙 없이 채우면 규칙이 채우는 중에 생긴다.

## 1. 표기 위치

L-03의 위치 범주를 따른다.

```text
신설 섹션 / 방법 / 감사의 글 / 표지 / 표기 없음
```

## 2. 표기 내용 (0~4점)

항목마다 1점. 합산한다.

| 항목 | 판정 |
|---|---|
| 도구명 | 특정 서비스를 이름으로 지목했는가 |
| 모델·버전 | 모델명 또는 버전을 적었는가 |
| 용도 | 어느 단계에 무엇에 썼는지 적었는가 |
| 검토·책임 문구 | 출력을 검토했고 책임이 작성자에게 있다고 적었는가 |

`AI의 도움을 받았다`만 있으면 0점이다. 도구를 특정하지 않으면 문서에서 무엇을 썼는지 확인되지 않는다.

## 3. 참조 축 (판단이 들어가는 칸)

| 축 | 값 | 출처 |
|---|---|---|
| 지원 수준 | 1 기본 교정 / 2 구조 편집 / 3 파생 콘텐츠 생성 / 4 새 콘텐츠 생성 / 5 평가·피드백 | L-01 |
| 사용 방식 | 탐색 / 전개 / 개작 / 각색 / 무분별 | L-02 |

이 두 칸에는 연구자의 판단이 들어간다. 코딩 값을 결론의 근거로 쓰지 않는다. 기록의 진술을 그대로 인용한다.

## 5. 마지막 행 — 대조

표기문이 말한 것과 프롬프트 기록이 보여주는 것이 같은지 본다. 이 행이 Q-S2를 답한다.

값은 셋이다.

| 값 | 의미 |
|---|---|
| 성립 | 표기문의 항목을 기록에서 찾을 수 있다 |
| 불성립 — 표기 부실 | 표기문이 항목을 말하지 않아 찾을 대상이 없다 |
| 불성립 — 자료 부재 | 표기와 기록이 모두 없다 |

**불성립은 결측이 아니다.** `성립 N건 + 불성립 M건`으로 적고 사유를 구분한다. 불성립이 나오는 것 자체가 결과다.

## 6. 기록하되 판정하지 않는 것

- 표기문에 없는 기록 항목 — 관찰로 남긴다. 미표기 사용으로 지목할지는 판정 규칙에 달렸다
- 부정 진술(`쓰지 않았다`)에 대응하는 기록의 부재 — 확인도 반증도 아니다
- 작성자의 동기 — 자료에 없다
