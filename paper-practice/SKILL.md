# 논문 실습

> 실제 논문이 아니라 **논문 쓰는 방법**을 한 바퀴 돌리는 스킬이다. 5,000자 한 편을 끝까지 통과시켜 전체 구조를 몸에 익힌다.

## 적용 후 남는 결과

1. 연구 질문 3개(핵심 1·보조 2)
2. 5섹션 목차와 섹션별 목표 자수
3. 문헌 3~5편의 원문 근거카드
4. 섹션별 초안
5. 문장–근거 대응표
6. 출처 표기와 참고문헌
7. 본문 5,000자 완성본
8. AI 사용 기록과 회고 5줄

## 보조 파일

| 파일 | 읽는 시점 |
|---|---|
| `references/evidence-rules.md` | STEP 3 — 자료 상태·원문 접근 절차·판본·충돌 4종·자료 유형 |

## 이 스킬을 쓰는 경우와 쓰지 않는 경우

| 상황 | 사용 |
|---|---|
| 논문 방법을 처음 익힌다 | 사용 |
| 수업·워크숍에서 연습 논문 한 편을 통째로 돌린다 | 사용 |
| 학부 졸업논문·학위논문·투고논문을 작성한다 | 사용하지 않음 |
| 실습 결과물을 제출용 논문으로 다듬는다 | 사용하지 않음 |

실습 결과물을 그대로 제출용 논문으로 쓰지 않는다. 자료 수와 검증 범위가 실제 논문 기준에 못 미친다.

## 실습 규모

| 섹션 | 목표 자수 | 단락 수 | 오늘 하는 일 |
|---|---|---|---|
| Ⅰ. 서론 | 700 | 2 | 마지막에 작성 |
| Ⅱ. 이론적 배경 | 1,500 | 3 | 문헌 3~5편 |
| Ⅲ. 연구 방법 | 700 | 2 | 실제 수행한 절차만 |
| Ⅳ. 연구 결과 | 1,300 | 3 | 본인이 모은 소규모 자료 |
| Ⅴ. 결론·논의 | 800 | 2 | 마지막에 작성 |
| 합계 | **5,000** | 12 | |

단락 하나는 300~600자, 5~7문장이다. 12개 단락이 실습 전체의 작업 단위다.

## 필요한 자료 (STEP 0에서 확인)

| 자료 | 최소 | 없으면 |
|---|---|---|
| 문헌 | 3~5편 (원문 접근 가능) | STEP 3에서 함께 찾는다 |
| 원자료 | 1건 (관찰 기록·사례·수집한 이미지·짧은 인터뷰 중 택1) | 논증형으로 전환해 문헌만으로 진행 |

원자료가 없으면 Ⅲ·Ⅳ를 문헌 기반 논증 장으로 바꾼다. 없는 자료를 만들지 않는다.

## 자료 확인 도구

| 도구 | 사용 | 시점 |
|---|---|---|
| 첨부 파일 읽기 | 사용자가 올린 PDF·이미지·메모를 자료로 쓴다 | STEP 3, STEP 5 |
| 사용 가능한 웹 검색 | 문헌 후보를 찾는다 | STEP 3 |
| 웹 원문 또는 첨부 PDF 열람 | 서지와 근거 위치를 확인한다 | STEP 3 |

## 절대 규칙

1. 사용자가 원하는 결과를 질문·목차에 미리 넣지 않는다.
2. `영향`·`효과`·`원인`은 그 관계를 확인할 설계가 있을 때만 쓴다.
3. 검색 결과의 제목·요약만으로 원문 내용을 확정하지 않는다.
4. 웹 원문 또는 첨부 파일을 열어 근거 위치를 확인한 자료만 E3로 둔다.
5. 확인하지 못한 저자·연도·제목·DOI·페이지를 만들지 않는다. 열지 않은 판본을 인용하지 않는다.
6. 자료에 없는 사실·수치·인용·경험·참여자 발언을 만들지 않는다.
7. 관찰한 것과 해석한 것을 한 문장에 섞지 않는다.
8. **참여자·작성자의 동기·의도를 판단하지 않는다. 부정도 판단이다.** `정직하지 않다`뿐 아니라 `정직성의 문제가 아니다`도 동기 판단이다. 자료에 없으면 긍정도 부정도 하지 않는다.
9. 충돌은 4종으로 구분해 적는다(자료 간·기준 경계·자료 내부·판본 간). 숨기거나 평균내지 않는다.
10. 선행연구·1차 자료·원자료를 구분한다. 규정 문서를 선행연구 고찰에 넣지 않는다.
11. 계획한 자료를 다른 것으로 대체하면 유형 변화와 대가를 보고한다.
12. 본문은 ~한다/~이다 평서형(문어체)으로 쓴다. ~합니다체와 혼용하지 않는다.
13. 서론·결론은 본론을 채운 뒤 마지막에 쓴다.
14. **판정 규칙을 확정하기 전에 집필로 넘어가지 않는다.** 질문의 핵심 개념을 무엇으로 판정할지 정하지 않으면 결과 장에서 규칙이 즉흥으로 생긴다.
15. 실습 결과물에는 `실습 원고` 표시를 유지한다.
16. 가상 자료를 쓰면 모든 결과에 `가상 예시`를 표시한다.
17. 사용자가 확인하기 전 질문·목차·해석을 확정하지 않는다.

## 전체 흐름

```text
STEP 0 실습 준비 확인
→ STEP 1 주제와 연구 질문 3개 + 판정 규칙
→ STEP 2 목차와 12칸 배치
→ STEP 3 자료 수집과 근거카드
→ STEP 4 이론적 배경 (1,500자)
→ STEP 5 방법·결과 (2,000자)
→ STEP 6 서론·결론 (1,500자)
→ STEP 7 문장–근거 점검과 출처 표기
→ STEP 8 완성본과 회고
```

각 단계가 끝나면 사용자 확인을 받는다. `끝까지 진행`이라고 하면 연속 실행한다.

권장 시간 배분: STEP 0~2에 20분, STEP 3에 30분, STEP 4~6에 40분, STEP 7~8에 20분. 자료 접근 상태에 따라 더 걸릴 수 있다.

# STEP 0. 실습 준비 확인

## 목표

실습을 시작하기 전에 손에 있는 것을 확인한다. 세 가지만 묻는다.

```text
1. 주제 한 줄
2. 지금 가진 자료 (문헌 몇 편, 원자료가 있는지)
3. 원자료 종류 (관찰 기록 / 사례 / 이미지 / 짧은 인터뷰 / 없음)
```

답을 받으면 실습 규모표(5,000자·12칸)를 보여주고, 오늘 끝까지 간다는 것을 알린다.

### 자료 상태에 따른 분기

| 상태 | 경로 |
|---|---|
| 문헌 3편 이상 + 원자료 1건 | 실증형 전체 경로 |
| 문헌만 있음 | 논증형. Ⅲ·Ⅳ를 개념·사례 분석 장으로 전환 |
| 둘 다 없음 | STEP 3에서 문헌을 함께 찾는다. 원자료는 논증형으로 대체 |

### 완료 기준

주제 한 줄, 자료 목록, 경로(실증형/논증형)가 정해졌다.

# STEP 1. 주제와 연구 질문 3개

## 목표

주제를 조사 가능한 질문 3개로 좁힌다.

### 질문 후보 5개

다섯 유형에서 하나씩 만든다.

| 유형 | 기본 질문 | 필요 자료 |
|---|---|---|
| 현상 | 무엇이 어떻게 나타나는가 | 관찰·기록 |
| 비교 | 무엇과 무엇이 어떻게 다른가 | 비교 가능한 두 조건 |
| 관계 | 무엇이 무엇과 어떻게 관련되는가 | 두 요소를 함께 확인한 자료 |
| 해석 | 무엇을 어떤 의미로 해석하는가 | 문헌·인터뷰 |
| 설계 | 어떤 원리·조건을 도출할 수 있는가 | 위 근거의 종합 |

각 후보에 `사용 가능 / 수정 후 가능 / 보류`를 붙인다. 판정 기준은 네 가지다.

- 범위: 5,000자 안에서 답할 수 있는가
- 중립성: 결과를 질문에 미리 넣지 않았는가
- 자료: 지금 가진 것으로 답할 수 있는가
- 윤리: 참여자·개인정보 문제가 없는가

### 확정

- `Q-MAIN` 핵심 1개 → 서론
- `Q-S1` 보조 1개 → 이론적 배경 (문헌으로 답하는 질문)
- `Q-S2` 보조 2개 → 결과 (자료로 답하는 질문)

이 ID는 실습 끝까지 유지한다. 사용자 승인 뒤에만 확정 표시한다.

### 판정 규칙 확정

질문 문구만 정하고 넘어가지 않는다. 질문에 든 핵심 개념(`대응`, `차이`, `상세도`, `유형` 등) 하나를 골라 **무엇으로 판정할지** 정한다. 이것을 정하지 않으면 결과 장에서 규칙이 즉흥으로 생기고, 그 규칙이 결과를 바꾼다.

절차는 셋이다.

1. 판정할 개념 하나를 지목한다.
2. 판정 방식 후보 2개를 만든다. 방향이 서로 달라야 한다(예: 문서에서 출발 / 기록에서 출발, 형식 기준 / 내용 기준).
3. 후보마다 **얻는 것과 잃는 것**을 적는다. 특히 **그 방식이 못 보는 것**을 적는다.

| 안 | 판정 방식 | 얻는 것 | 잃는 것 |
|---|---|---|---|
| A | | 판정이 기계적이고 재현된다 | |
| B | | | 연구자 판단이 들어가 재현성이 낮다 |

사용자가 고른다. 고른 뒤 **그 선택이 자료에 대입되면 어떻게 갈리는지** 사례별로 미리 보여준다. 대조·비교가 성립하지 않는 사례가 나오면 그것을 결손으로 부르지 않는다. **불성립도 결과다.** 사유를 구분해 적으면 된다.

버린 안이 잃게 한 것은 결론의 한계에 적는다. STEP 5의 결과 장은 이 규칙을 그대로 따르고, 규칙 밖의 것을 발견하면 판정하지 않고 관찰로만 남긴다.

판정 방식이 특정 자료의 E3 확보에 걸려 있으면(예: B안이 문헌 L-01의 분류 축을 쓴다면) STEP 3 결과에 따라 되돌아올 수 있음을 알린다.

### 완료 기준

질문 3개가 서로 다른 일을 하고, 각 질문이 어느 섹션에서 답해지는지 정해졌으며, 핵심 개념의 판정 규칙이 확정됐다.

# STEP 2. 목차와 12칸 배치

## 목표

5,000자를 12개 단락 칸으로 나누고 각 칸의 역할을 한 줄로 적는다.

| 칸 | 섹션 | 단락 역할 | 답할 질문 | 자수 | 상태 |
|---|---|---|---|---|---|
| 1-1 | 서론 | 배경·문제 | Q-MAIN | 350 | 앞 칸 대기 |
| 1-2 | 서론 | 연구 질문·구성 | Q-MAIN | 350 | 앞 칸 대기 |
| 2-1 | 이론적 배경 | 개념 정의 | Q-S1 | 500 | 자료 대기 |
| 2-2 | 이론적 배경 | 선행연구 고찰 | Q-S1 | 500 | 자료 대기 |
| 2-3 | 이론적 배경 | 종합·연구 공백 | Q-S1 | 500 | 앞 칸 대기 |
| 3-1 | 방법 | 대상·자료 | Q-MAIN | 350 | — |
| 3-2 | 방법 | 절차·판단 기준 | Q-MAIN | 350 | — |
| 4-1 | 결과 | 확인된 것 1 | Q-S2 | 450 | 자료 대기 |
| 4-2 | 결과 | 확인된 것 2 | Q-S2 | 450 | 자료 대기 |
| 4-3 | 결과 | 해석 | Q-S2 | 400 | 앞 칸 대기 |
| 5-1 | 결론 | 요약 | Q-MAIN | 400 | 앞 칸 대기 |
| 5-2 | 결론 | 한계·다음 질문 | — | 400 | 앞 칸 대기 |

- 상태는 `완료 / 자료 대기 / 앞 칸 대기` 세 값만 쓴다.
- 논증형이면 3장·4장을 개념·사례 분석 장으로 바꾸고 칸 수는 유지한다.
- 이 표는 잠정이다. 문헌을 읽으면 2장 소절이 갈라지거나 합쳐진다. 칸이 바뀌는 것은 정상이다.

### 질문 배정 규칙 (위 표는 기본값이며 아래 규칙이 우선한다)

| 규칙 | 내용 |
|---|---|
| Q-MAIN이 현상 질문이면 | **결과 첫 칸(4-1)을 Q-MAIN에 배정한다.** Q-MAIN이 서론·결론에만 걸리면 본론에 답이 없는 논문이 된다 |
| Q-MAIN이 해석 질문이면 | 이론적 배경에 Q-MAIN을 함께 건다. Q-S1과 칸을 나눈다 |
| Q-S2가 비교 질문이면 | 비교 조건이 갈리는 칸(4-2)에 둔다 |
| 문헌이 서로 다른 축을 담당하면 | 2-1이 무거워진다. STEP 3에서 E3가 확보되면 2-1을 두 소절로 나눈다 |

배정을 바꿨으면 어디를 왜 바꿨는지 한 줄로 적는다.

### 완료 기준

12칸이 채워졌고, 사용자가 오늘 채울 순서(2장 → 3·4장 → 1·5장)를 확인했다.

# STEP 3. 자료 수집과 근거카드

## 목표

인용할 수 있는 자료와 인용할 수 없는 자료를 가른다. 실습의 핵심 단계다.

**시작하기 전에 `references/evidence-rules.md`를 읽는다.** 자료 상태, 원문 접근 절차, 판본 규칙, 충돌 4종, 자료 유형 구분이 그 파일에 있다.

## 절차

1. 한국어·영어 검색어를 각각 만든다(대상어 + 현상어 + 맥락어).
2. 사용 가능한 웹 검색으로 후보를 찾는다 → E0.
3. 후보의 웹 원문 또는 첨부 PDF를 연다 → E1~E2.
4. 직접 열리지 않으면 공개본을 찾는다(프리프린트·기관 리포지터리·PMC). 페이월과 로봇 차단은 우회하지 않는다.
5. 근거 위치(페이지·표·절)를 확인한다 → E3.
6. 목표는 E3 3~5편이다.

E0~E2를 근거로 쓰지 않는다. 열지 못한 자료는 `원문 확인 실패`로 적고 사용자에게 PDF를 요청한다. KCI·RISS·DBpia가 막히는 것은 정상이며 실습의 일부다.

E3가 3편 미만이면 STEP 4로 넘어가지 않는다. 사용자에게 원문 PDF 추가, 주제 축소, 실습 중단 가운데 하나를 선택받는다. 확인하지 못한 자료로 분량을 채우지 않는다.

## 근거카드

E3마다 만든다. 형식은 `evidence-rules.md` 6절에 있다. 자료 유형·판본·접근 경로를 반드시 적는다.

| 항목 | 내용 |
|---|---|
| 자료 대체 | 계획한 자료를 못 구해 다른 것을 넣었으면 유형 변화와 대가를 적는다 |
| 판본 | 프리프린트를 열었으면 게재본의 존재를 확인하고, 열지 않은 판본은 인용하지 않는다 |
| 충돌 | 4종으로 구분해 적는다. 봉합하지 않는다 |
| 공백 | 못 찾은 것을 `연구 공백`이라고 부르지 않는다 |
| 칸 조정 | E3 구성에 따라 2장 칸이 바뀌면 여기서 조정한다 |

## 완료 기준

- E3가 3편 이상이고, 각 카드에 원문 위치와 말할 수 없는 범위가 있다.
- 자료 유형이 구분됐고, 대체가 있었으면 보고됐다.
- 충돌과 공백이 종류별로 적혔다.

# STEP 4. 이론적 배경 (1,500자)

## 목표

칸 2-1·2-2·2-3을 채운다. 각 단락은 태그 초안을 거쳐 만든다.

### 태그 초안

```text
[근거] 문헌이 말한 것 (자료 ID·위치)
[해석] 연구자가 읽어 낸 것
[한계] 지금 자료로 말할 수 없는 것
```

관찰 태그는 쓰지 않는다. 문헌 고찰에는 관찰이 없다.

### 단락 구조

| 칸 | 구조 |
|---|---|
| 2-1 | 개념 범위 → 자료별 정의 → 이번 실습의 사용 범위 |
| 2-2 | 연구 A(저자·연도) → 연구 B(저자·연도) → 차이 |
| 2-3 | 종합 → 남은 공백 |

- 각 문헌을 저자·연도로 귀속한다. 서로 다른 문헌의 결과를 하나의 결론으로 묶지 않는다.
- 직접 인용은 만들지 않는다. 필요하면 원문 후보와 위치를 표시해 STEP 7로 넘긴다.
- 자료 부족을 `연구 공백`으로 부르지 않는다. 못 찾은 것과 없는 것은 다르다.

### 완료 기준

세 칸이 채워졌고, 태그를 지운 뒤에도 근거와 해석의 경계가 문장에 남는다.

---

# STEP 5. 방법·결과 (2,000자)

## 목표

칸 3-1·3-2·4-1·4-2·4-3을 채운다.

### 방법 (700자)

실제로 한 것만 쓴다. 수집하지 않은 자료, 밟지 않은 절차를 만들지 않는다.

```text
3-1: 무엇을 대상으로 했고 어떤 자료를 썼는가
3-2: 어떤 순서로 봤고 무엇을 기준으로 판단했는가
```

실습 규모이므로 표본이 작다. 그 사실을 방법에 적는다.

### 결과 (1,300자)

```text
[관찰] 자료에서 직접 보이는 것 (자료 ID·위치)
[근거] 그 관찰을 뒷받침하는 기록
[해석] 연구자의 판단 — `~로 해석할 수 있다` 강도
[한계] 이 자료로 말할 수 없는 것
```

- 관찰과 해석을 한 문장에 섞지 않는다.
- 사례의 존재를 효과의 증거로 바꾸지 않는다.
- 표본이 작으면 일반화 문장을 쓰지 않는다.
- **동기·의도를 판단하지 않는다.** 자료에 동기가 없으면 긍정도 부정도 하지 않는다. `A가 아니라 B다` 형식으로 A를 부정하는 것도 A에 대한 판단이다. 같은 칸에서 `동기는 자료에 없다`고 적고 동기를 부정하면 자기 문장 안에서 모순이 난다.
- STEP 1에서 정한 판정 규칙 밖의 것을 발견하면 판정하지 않고 관찰로만 남긴다. 버린 안이 잃게 한 것이 여기서 드러나는 것은 정상이다.
- 비교·대조가 성립하지 않는 사례는 결측이 아니다. `성립 N건 + 불성립 M건`으로 적고 불성립의 사유를 구분한다.

### 논증형일 때

3장은 개념 정리, 4장은 사례 분석으로 바꾼다. 자료 유형만 문헌·사례로 달라지고 태그 구조는 같다.

### 완료 기준

다섯 칸이 채워졌고, 관찰·근거·해석·한계가 분리돼 있다.

---

# STEP 6. 서론·결론 (1,500자)

## 목표

본론이 끝났으므로 이제 앞뒤를 쓴다.

### 서론 (700자)

```text
1-1: 현상 → 기존 설명 → 남은 문제
1-2: 연구 질문(Q-MAIN·Q-S1·Q-S2) → 논문 구성
```

연구 필요성을 과장하지 않는다. 본론에 없는 주장을 서론에서 예고하지 않는다.

### 결론 (800자)

```text
5-1: 질문별로 무엇이 확인됐는가 (새 결과를 추가하지 않는다)
5-2: 이 실습으로 말할 수 없는 것 → 다음 질문
```

5-2에 실습 규모의 한계를 적는다. 문헌 3~5편, 원자료 1건, 표본 크기가 그것이다.

### 완료 기준

서론의 질문과 결론의 답이 같은 ID로 대응한다.

# STEP 7. 문장–근거 점검과 출처 표기

## 목표

12칸 전체에서 근거 없는 문장을 찾아낸다.

### 문장–근거 대응표

| 문장 | 칸 | 역할 | 질문 | 자료 ID·위치 | 상태 |
|---|---|---|---|---|---|

상태: `근거 확인 / 연구자 해석 / 표현 완화 / 추가 확인 / 삭제 후보`

근거 없는 문장은 삭제하거나 `추가 확인`으로 분리한다. 실습에서는 삭제 후보가 나오는 것이 정상이다. 몇 건이 나왔는지 세어 STEP 8 회고에 적는다.

### 출처 표기

실습에서는 APA 7판 저자–연도 방식을 사용하되 자료 유형에 맞는 형식을 고른다.

```text
본문: (저자, 연도) 또는 저자(연도)
학술지 논문: 저자. (연도). 제목. 저널, 권(호), 쪽. DOI
프리프린트: 저자. (연도). 제목. 저장소명. 식별자 또는 URL
기관 보고서·규정: 기관명. (연도). 문서 제목. 발행기관. URL
웹 문서: 저자·기관명. (연도 또는 날짜). 문서 제목. 사이트명. URL
```

- E3 자료만 참고문헌에 넣는다.
- 원문에서 확인한 서지만 적는다. 확인하지 못한 쪽수·DOI는 만들지 않고 `확인 필요`로 표시한다.
- 작업용 자료 ID(E-01)를 본문에서 지우고 저자–연도로 바꾼다.

### AI 흔적 점검

- ~합니다체·구어체가 남아 있으면 ~한다체로 바꾼다.
- 과장 형용사, 모호 부사, 내용 없는 연결어(`나아가`, `이를 통해`, `중요한 역할`)를 제거한다.
- 근거에 묶인 헤지(`~로 보인다`, `~와 관련될 수 있다`)는 유지한다. 이것은 학술 강도 통제다.
- 사실·수치·저자·연도·주장 강도는 바꾸지 않는다.

### 완료 기준

근거 없는 문장이 0건이거나 분리됐고, 참고문헌에 E3만 있다.

# STEP 8. 완성본과 회고

## 목표

한 편을 붙여서 내보내고, 무엇을 익혔는지 남긴다.

### 완성본 출력

```text
[실습 원고]
제목:
연구 질문: Q-MAIN / Q-S1 / Q-S2

Ⅰ. 서론
Ⅱ. 이론적 배경
Ⅲ. 연구 방법
Ⅳ. 연구 결과
Ⅴ. 결론·논의

참고문헌
AI 사용 기록
```

- 본문 자수를 섹션별로 함께 표시한다.
- `실습 원고` 표시를 지우지 않는다.
- 파일이 필요하면 .docx로 저장한다.

### AI 사용 기록

```text
나는 Claude의 paper-practice를 연구 질문 설계, 자료 선별, 단락 구조와 문장 초안에 사용했다.
최종 질문·자료 적합성·해석·인용·문체는 원문을 대조해 직접 확인·수정했다.
```

### 회고 5줄

```text
1. E3까지 올라간 자료 / E0~E2에서 멈춘 자료: (편 수)
2. 삭제 후보로 분리된 문장: (건 수)
3. 자료 사이 충돌이 있었는가:
4. 가장 오래 걸린 칸:
5. 실제 논문으로 확장한다면 먼저 채울 것:
```

이 5줄이 실습의 실제 산출물이다. 원고보다 이쪽이 남는다.

### 사용 범위 확인

실습 원고를 그대로 제출하거나 실제 연구 결과로 제시하지 않는다. 학위논문·투고논문은 소속 기관의 연구윤리 지침과 지도 절차에 따라 별도로 기획·수행·검증한다.

### 완료 기준

5,000자 완성본, 참고문헌, AI 사용 기록, 회고 5줄이 있다.
