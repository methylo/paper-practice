# 근거 규칙

자료를 인용 가능한 상태로 올리는 절차와, 자료가 서로 어긋날 때의 처리 규칙이다. STEP 3에서 읽는다.

## 1. 자료 상태 E0~E3

| 상태 | 의미 | 사용 |
|---|---|---|
| E0 | 검색 결과·목록만 봤다 | 인용 금지 |
| E1 | 서지·초록까지 확인했다 | 인용 금지 |
| E2 | 원문을 열었으나 근거 위치를 못 찾았다 | 인용 금지 |
| E3 | 원문에서 근거 위치(페이지·표·절)를 확인했다 | **인용 가능** |

E0~E2를 근거로 쓰지 않는다. 이 구분을 체감시키는 것이 실습의 목적 중 하나다. 목표는 E3 3~5편이다.

E1에서 멈춘 자료도 기록에 남긴다. 지운 자료가 아니라 **인용하지 않은 자료**다. 회고에서 이 편 수를 센다.

## 2. 원문 접근 절차

### 순서

1. 웹 원문 또는 사용자가 첨부한 PDF를 직접 연다.
2. 실패하면 아래 허용 경로를 순서대로 시도한다.
3. 모두 실패하면 E1에 두고 `원문 확인 실패`로 적는다. 사용자에게 PDF 첨부를 요청한다.

### 허용 경로 (공개본을 찾는 것)

| 경로 | 예 | 주의 |
|---|---|---|
| 프리프린트 | arXiv, bioRxiv, SSRN | 게재본과 수치가 다를 수 있다 → 3절 |
| 기관 리포지터리 | 대학 리포지터리, 저자 개인 페이지 | 저자 원고(AAM)일 수 있다. 페이지 번호가 게재본과 다르다 |
| 공개 아카이브 | PMC, DOAJ, 저널 오픈액세스판 | |
| 발행 기관 원문 | 대학·학회·정부 기관이 직접 공개한 PDF | 1차 자료다 → 5절 |

같은 자료의 공개본을 찾는 것은 우회가 아니다. 접근 경로를 바꾸는 것이다.

### 금지 경로

- 페이월·로그인 우회
- 로봇 차단(`robots.txt`)을 우회하는 재시도
- 해적 사이트

KCI·RISS·DBpia는 자동 접근이 막힌다. 이것은 정상이며 실습의 일부다. 막힘을 겪고 E1에 두는 경험이 자료 상태 구분을 몸에 남긴다.

### 기록

접근 실패는 감추지 않는다. 어떤 경로로 열었는지 근거카드에 적는다.

```text
- 접근: arXiv 원문 열람 실패 → 기관 리포지터리 공개본으로 전문 열람
```

## 3. 판본 규칙

프리프린트를 열었으면 게재본의 존재를 확인한다. 두 판본은 수치가 다를 수 있다.

| 상황 | 처리 |
|---|---|
| 프리프린트만 열었다 | 프리프린트를 인용한다. 서지에 프리프린트임을 명시한다 |
| 게재본이 있으나 열지 못했다 | **게재본을 인용하지 않는다.** 열지 않은 판본은 E1이다. 게재본이 존재한다는 사실을 방법 또는 한계에 적는다 |
| 두 판본의 수치가 다르다 | 열어서 확인한 판본의 수치를 쓴다. 다른 판본에 다른 수치가 있다는 사실을 함께 적는다 |
| 게재본을 열었다 | 게재본을 인용한다 |

연도 표기는 열람한 판본을 따른다. 프리프린트 2023년판을 열고 게재본 2024년을 붙이지 않는다.

## 4. 충돌 4종

충돌을 숨기거나 평균내지 않는다. 종류를 구분해 적는다.

| 종류 | 내용 | 처리 |
|---|---|---|
| **자료 간** | 두 문헌이 다른 결론을 말한다 | 저자·연도로 각각 귀속해 나란히 적는다 |
| **기준 경계** | 같은 행위를 두고 기준선이 다른 곳에 그어져 있다 | 어느 쪽이 옳은지 판정하지 않는다. 경계가 갈린다는 사실을 적는다 |
| **자료 내부** | 한 자료의 결과 절과 논의 절 수치가 어긋난다 | 결과 절 수치를 쓴다. 어긋남을 한계로 남긴다 |
| **판본 간** | 같은 연구의 판본마다 수치가 다르다 | 3절을 따른다 |

봉합 문장을 쓰지 않는다. `대체로 ~하다`, `종합하면 ~로 볼 수 있다`로 두 축을 하나로 만들면 충돌이 사라진 것처럼 보인다.

## 5. 자료 유형 구분

문헌과 1차 자료는 다른 칸에 들어간다.

| 유형 | 예 | 들어가는 칸 |
|---|---|---|
| 선행연구 | 논문, 학위논문, 학술 리뷰 | 선행연구 고찰 (2-2) |
| 1차 자료 | 규정·가이드라인·정책 문서, 지침 원문 | 개념 정의(2-1) 또는 종합(2-3)에서 **사례**로 |
| 원자료 | 관찰 기록, 제출물, 사례, 인터뷰 | 결과 (4-1~4-3) |

규정 1건을 선행연구 고찰에 넣으면 근거의 종류가 섞인다. 규정은 무엇을 요구하는지 말할 뿐 무엇이 확인됐는지 말하지 않는다.

### 자료를 대체할 때

계획한 자료를 못 구해 다른 것을 넣으면 **보고한다.** 대체는 조용히 하지 않는다.

```text
- 예정: 국내 선행연구 1편
- 실제: 국내 대학 규정 원문 1건 (KCI 차단으로 문헌 확보 실패)
- 유형 변화: 선행연구 → 1차 자료
- 대가: 선행연구 고찰이 3편으로 줄어든다. 규정은 2-1 또는 2-3에서 사례로 다룬다
```

유형이 바뀌면 칸이 바뀐다. 칸을 바꾸지 않고 자료만 갈아 끼우면 그 칸의 역할이 무너진다.

## 6. 근거카드 형식

E3마다 만든다.

```text
- 자료 ID: E-01
- 답할 질문: Q-S1
- 자료 유형: 선행연구 / 1차 자료 / 원자료
- 서지: 저자(연도). 제목. 저널, 권(호), 쪽. DOI
- 판본: 프리프린트 / 게재본 / 저자 원고 — 열람한 것
- 접근: (직접 fetch / 미러 / 첨부 PDF)
- 원문 위치: (페이지·표·절)
- 확인 내용: (원문이 말한 범위 그대로)
- 말할 수 있는 범위:
- 말할 수 없는 범위:
- 한계: (대상·방법·맥락이 이번 실습과 다른 지점)
```

`말할 수 없는 범위`를 비워 두지 않는다. 이 칸이 STEP 7의 삭제 후보를 미리 잡는다.

## 7. 공백

- 못 찾은 것과 없는 것은 다르다. 자료를 확보하지 못한 상태를 `연구 공백`이라고 부르지 않는다.
- `이번 조사에서 확인하지 못했다`로 적는다.
- 확보한 자료 전부가 이번 대상과 다른 맥락이면(대상·전공·국가·매체), 그 거리를 한계로 적는다. 이것은 공백이 아니라 **적용 거리**다.
